# RentAssure

RentAssure is a multi-vendor rental marketplace where local shop owners list furniture, appliances, and electronics for rent, and customers subscribe to rent them monthly instead of buying. The platform doesn't own inventory — vendors manage their own stock and delivery, while RentAssure handles bookings, payments, and vendor payouts.

## Features

- Vendor onboarding and item listing with rental plans
- Location-based item discovery
- Monthly rental subscriptions with refundable deposits
- Booking lifecycle tracking (reserved → active → returned)
- Automated payments and vendor payouts via Stripe Connect
- Vendor, customer, and admin dashboards
- Ratings and reviews

## Tech Stack

- **Backend:** .NET Core Web API
- **Frontend:** React
- **Database:** PostgreSQL
- **Payments:** Stripe
